Игра в города по Российской Федерации

Проект был создан на уроках По python pro на платформе учи дома, сделан в развлекательных целях. 

@bot.message_handler - реакция на сообщение от пользователя и вывод сообщения от бота 

bot.infinity_polling() - постоянная проверка нет ли сообщения от пользователя

Перед началом использования данного проекта заходим в данного BotFather и создаем телеграм бота и копируйте токен своего бота и вставляйте TOKEN = 'ваш токен'(не публикуйте в гитхаб с его видимостью) нажимаем /start, после этого в среде разработки нажимаете на старт кода и снова пишите боту /start, после этого у вас появятся меню управлению снизу. 
Есть несколько команд в боте /game, /stop, /start, /info, /stats, все они вам не понадобятся кроме /start, ведь его нужно будет использовать каждый раз, когда, что то меняете в коде, остальное есть в кнопках управления. Для добавления новых городов редактируйте список cities.txt также используется encoding='Windows-1251' учитывайте это меняя файл с списком городов. Удачного пользования ботом!
